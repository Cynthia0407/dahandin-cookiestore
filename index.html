🛡️ 다했니 API Key 보관 방식

🔐 선생님 전용 설정 비밀번호로도 사용됩니다.
처음 저장할 때 입력한 이 비밀번호가 알바생 모드에서 설정 화면에 들어갈 때 필요한 비밀번호입니다. 학생 알바생에게 알려주지 말고, 선생님만 기억해 주세요. 영문·숫자를 섞은 8자 이상의 비밀번호를 권장합니다.

AES-GCM + PBKDF2 방식으로 브라우저에서 암호화합니다. 비밀번호 자체는 Drive나 브라우저 저장소에 저장하지 않습니다. 저장 후에는 이 화면에서 입력란을 숨기며, 다른 기기나 새로고침 후에는 다시 입력해야 할 수 있습니다.

비밀번호를 잊으면 암호화된 API Key는 복구할 수 없습니다.

🔒 선생님 비밀번호 설정 완료 · 이 화면을 닫으면 다시 입력해야 할 수 있습니다.

🔒 Drive에 암호화된 API Key가 있습니다. 다른 기기이거나 새로고침한 경우 비밀번호를 입력해 잠금을 해제하세요.

⚠️ 암호화를 끄면 다했니 API Key가 드라이브 앱 데이터에 평문으로 저장됩니다. 이 계정의 보안에 특히 유의하세요.

☁️ 동기화 및 개인정보 안내

① Google 로그인 후 Drive 접근 권한을 허용합니다. ② 이 계정의 이전 상점 데이터를 불러옵니다. ③ 상점 저장·구매·환불·장부 변경 시 연결된 드라이브에 저장을 시도합니다. 다른 기기에서는 같은 Google 계정으로 로그인한 뒤 불러오세요. 실시간 공동편집은 지원하지 않으며 동시 사용하면 마지막 저장 내용으로 덮어쓸 수 있습니다.

개인정보: 학생 이름·번호·쿠키 잔액·판매 장부·학생 코드가 본인 구글 계정의 숨겨진 앱 데이터 폴더에 보관됩니다. API Key는 기본적으로 별도 비밀번호로 암호화하며, 다른 데이터는 암호화하지 않습니다. 앱은 일반 드라이브 파일의 조회·수정 권한을 요청하지 않습니다. 공개 또는 공동 계정보다 교사용 Google 계정을 권장합니다. 계정·기기 공유에 유의하세요.

구글 계정마다 데이터는 서로 분리됩니다. 로그인 자체가 다른 계정으로 데이터를 공유하는 것은 아닙니다. 사이트 관리자가 Google OAuth 설정을 완료하고, 이용자가 권한을 승인해야 작동합니다.
